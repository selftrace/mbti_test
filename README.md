# mbti_test

The text data was first cleaned by removing URLs, punctuation, numbers and unnecessary whitespace before being converted into numerical features using TF-IDF. A Logistic Regression model was then trained on the processed data to learn the differences between each personality type.

The project includes:

Loading and exploring the dataset,
Text preprocessing and cleaning,
TF-IDF feature extraction,
Train/test split,
Logistic Regression model training,
Model evaluation using accuracy, confusion matrix and classification report,
Predicting personality types from custom user input,
Displaying the words that most strongly influence one personality type,
Technologies,
Python,
Pandas,
Scikit-learn,
Regular Expressions (re),

## Dataset

MBTI Personality Type Dataset from Kaggle.
